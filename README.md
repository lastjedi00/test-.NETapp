# Practice To-Do

A tiny to-do list web app (plain HTML, CSS and JavaScript) built for practicing Git and GitHub.

## Run it

No installation needed. Double-click `index.html` to open it in your browser.

## Files

| File | What it does |
|------|--------------|
| `index.html` | The page structure |
| `style.css` | Colors and layout |
| `script.js` | Add, finish, delete and save tasks |
| `settings.js` | App name and subtitle (edited in the practice exercises) |
| `GUIDE.md` | The step-by-step Git and GitHub guide |

## Start here

Open `GUIDE.md` and follow it from Part 1.
